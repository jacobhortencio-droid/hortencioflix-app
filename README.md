# Hortêncioflix — Android TV

Versão Android TV / Google TV da Hortêncioflix: add-ons do Stremio, conta Stremio (add-ons, biblioteca e progresso), TorBox via Torrentio, TV ao vivo (M3U / Xtream / listas públicas), leitor Media3 com legendas, faixas de áudio, troca de fonte, saltar introdução, próximo episódio e mini-leitor.

O APK é compilado automaticamente pelo GitHub Actions a cada envio para `main` e publicado em **Releases** e no ramo `apk`.
